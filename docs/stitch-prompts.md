# Google Stitch — Prompt Pack

Ashram School Pathraj · "Aurora Glass" Spatial Glassmorphism design system.

**How to use in Stitch (stitch.withgoogle.com):**
1. Start a new project. Paste **PROMPT 0 — GLOBAL STYLE** first to lock the visual language.
2. Then generate each screen by pasting its prompt. Every screen prompt repeats the style keywords so consistency holds even if you generate them separately.
3. Tip: keep "Mode = Experimental / high detail" for the glass effects, and set device to Desktop first, then ask Stitch to "make a mobile version" of each screen.

## PROMPT 0 — GLOBAL STYLE (paste once)

> Design a premium, modern, enterprise-grade SaaS website inspired by Apple, Linear, Vercel and Raycast. Visual language: **spatial glassmorphism** — frosted translucent glass panels, layered depth, backdrop blur, soft ambient shadows, floating UI, bento-grid layouts.
>
> **Colors:** background is a soft light lavender gradient from #F8F7FC to #FFFFFF. Primary brand purple #7C3AED (active states, links, important data, icons, brand). Accent orange #F97316 (CTAs, attention). Headings #1A1A2E, body text #6B7280, secondary text #9CA3AF. Glass surfaces are rgba(255,255,255,0.70) with a 1px rgba(255,255,255,0.55) border and 24px backdrop blur. Restrained palette — never neon.
>
> **Background environment:** large soft blurred gradient orbs (one purple #7C3AED, one orange #F97316) at low opacity, plus a very faint dot grid. Subtle, never distracting.
>
> **Typography:** headings in Space Grotesk (600/700), body in Inter (400/500). Display 48–64px, H1 40–48px, H2 30–36px, body 14–18px.
>
> **Components:** glass cards with 24px radius, soft internal highlight, wide diffused shadow, slight float. Buttons 16px radius, 44–48px tall — primary = purple gradient, CTA = orange gradient, secondary = transparent glass. Inputs 12px radius, glass fill, purple focus glow. Lucide-style thin line icons in purple or orange glass tiles. Compact translucent badges. Micro-interactions: hover translateY(-2px), soft shadow lift, spring modals.
>
> **Layout:** floating sticky glass navbar (rounded, blurred), generous 8px-based spacing, bento grids mixing small/medium/large/wide cards. 8px spacing scale. Fully responsive (375 / 768 / 1024 / 1440px) with proper mobile compositions, not just scaled-down desktop.
>
> This is a **bilingual (English + Marathi/Devanagari) government school website**. Keep it elegant, minimal, high-end and production-ready.
